# Changing or Cancelling an Order

## Change shipping address
You can change the shipping address free of charge while the order status is "processing" (before it ships). Once an order has shipped, the address cannot be changed — the carrier may offer a redirect from the tracking page.

## Cancel an order
Orders can be cancelled for a full refund while they are still "processing". After shipping, use the standard returns process.

## Change items
We can't add or swap items on an existing order. Cancel it while it is processing and place a new order instead.
